# Prompt Vault

Personal Higgsfield-style prompt library.

## Features
- Store full prompts with title, category, aspect ratio, target tools (Kling, Grok, Magica, Hedra, Seedance)
- Search + filter by category and tool
- One-click copy
- Favorites
- Negative prompts and tags
- Export / Import JSON
- Local storage (data stays in your browser)

## How to use
1. Open `index.html` in any browser.
2. Click **+ New Prompt** to add.
3. Paste prompts from Director Cut, Movie Skit, Walkway, etc.
4. Click a card → **Copy Prompt** and paste into Kling / Grok / Magica / Hedra.

## Categories preloaded
Director Cut, Movie Skit, Walkway, Character, LJR / Music, Real Estate, Cinematic, Other

Data lives in your browser’s localStorage. Export regularly if you want a backup.
